# Berlin Sub-3 – Treningsapp

Personlig treningslogg og fremgangssporing mot sub-3:00 på Berlin Marathon 2026.

## Innhold
- **Dashboard** – nedtelling til Berlin og Bergen, nøkkeltall, akilles-status
- **Treningslogg** – ukentlig logging av km, TSS, watt, HRV, søvn og akilles
- **Fremgang** – grafer for volum, watt, løpsøkonomi, HRV og intensitetsfordeling
- **Rødbeteprotokoll** – opplastingsplan for Beet It Nitrate 3000

## Oppsett lokalt

```bash
npm install
npm start
```

## Deploy til Vercel

1. Push til GitHub
2. Logg inn på vercel.com med GitHub-konto
3. Klikk "New Project" → velg dette repository
4. Klikk "Deploy" – ferdig

## Oppdatering

All kode skrives og vedlikeholdes via Claude. Kopier oppdaterte filer hit og push til GitHub – Vercel deployer automatisk.
